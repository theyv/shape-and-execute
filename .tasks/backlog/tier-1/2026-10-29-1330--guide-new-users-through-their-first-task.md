# Intent: Guide new users through their first tasks

## Problem

A new user needs to learn how shape-and-execute works. Reading the documentation should not be
necessary to get started and learn the workflow.

## Goal

Recognize a new installation and offer the user guidance during their first few tasks. Teach the
skill through tips shown while the user works.

### Success means

- A new user is offered the guidance rather than having it imposed on them.
- A user who accepts sees helpful tips during their first few tasks and learns how to use the
  skill through the normal workflow.
- A user can get started and learn to use the skill without reading documentation first.

## Proposed outcome

Explore how to detect a new installation, offer guidance, and show relevant tips as tasks proceed.
Decide how many tasks the guidance covers and how users can control it.

## Affected users and systems

New users of the skill and the task workflow where guidance appears.

## Open questions

- How should a new installation be recognized, and how should guidance progress be recorded?
- When and where should tips appear, and what should they teach?
- How many tasks should guidance cover? Can users stop, resume, or revisit it?
