# Intent: Cross-project active task overview in the viewer

## Problem

The owner wants one place to see active tasks across all projects in the viewer.

## Goal

Explore a shared overview screen that brings together active tasks from all projects.

### Success means

- The viewer offers one overview of active tasks across all projects.
- Each task shows which project it belongs to.

## Constraints

- [human, 2026-11-03] Tier 2. Keep this idea for further consideration.
- The screen design and implementation scope remain open.

## Open questions

- How should the viewer discover projects and their tasks?
